# LeoneClient
<img width="32" height="32" alt="image" src="https://github.com/user-attachments/assets/953d3826-42e5-4374-86f2-48b9f901c77c" />

This is a utility mod for LeoneMC with the following functions:

**Auto-join sub-server:*** 
Automatically join a server of your choice when you enter the hub

**Quick Ender Chest commands:**
/ec <page>
/enderchest <page>

**Custom action bar system:**
Separate regular and combat bars
Optional merged display
Draggable position editor

**Combat tag timer HUD shown as a vanilla status effect**

**Suppress LeoneMC staff recruitment alerts in chat**

**Block resource pack prompts in titles/subtitles**

**Anti-Mute chat filtering with configurable replacement text**
discrimination
death wishes
swears
advertisements

**Suppress some instances of log spam**

**Configurable via Mod Menu + keybind**
